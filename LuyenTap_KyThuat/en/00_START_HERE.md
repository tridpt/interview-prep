# 🛠️ Technical Practice (fundamentals + quick review)

This **general** folder reviews foundational topics commonly asked in interviews, **tied to the tech in the 6 projects** of this pack (FastAPI/Flask Python, vanilla JavaScript/PWA, Leaflet, IndexedDB, cryptography, OAuth...).

## Read by need

| # | File | When to read |
|---|------|--------------|
| 1 | `01_JAVASCRIPT_FUNDAMENTALS.md` | For frontend/Node/fullstack roles |
| 2 | `02_PYTHON_FUNDAMENTALS.md` | For backend/AI/Python roles |
| 3 | `03_WEB_REALTIME_FUNDAMENTALS.md` | HTTP, REST, streaming, PWA, async — almost always needed |
| 4 | `04_SYSTEM_DESIGN.md` | Rounds with a system-design question |
| 5 | `05_CODING_WHITEBOARD.md` | Coding/algorithm whiteboard rounds |
| 6 | `06_FLASHCARDS.md` | Quick Q&A review (60+ cards) before go-time |
| 7 | `07_CS_FUNDAMENTALS.md` | Git, Docker, SOLID, complexity, basic crypto |
| 8 | `08_MERMAID_DIAGRAMS.md` | Architecture/flow diagrams to draw quickly |

## How to use
1. **Prioritize the language relevant** to the role (JS for frontend/Node, Python for backend/AI).
2. **Web/Real-time + CS fundamentals** are worth it for everyone.
3. Before the interview: skim `06_FLASHCARDS.md` + `08_MERMAID_DIAGRAMS.md`.

> ⚠️ This reviews **general fundamentals**. The "how I built my project" part lives in the per-project docs — don't mix them up. Interviewers love when you connect fundamentals to a real project ("I used async because calling the LLM takes a few seconds...").
