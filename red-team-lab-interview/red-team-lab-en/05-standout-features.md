# 05 — Standout Features

1. **Seven direct and five indirect levels:** compare attacker chat with attacker-controlled retrieved data; each level explains defenses, not just a score.
2. **Deterministic simulator:** reproducible lessons and tests without API costs, at the expense of realism for actual models.
3. **Multiturn level seven:** `state.primed` demonstrates how earlier context can influence a later turn in the modeled engine.
4. **Configurable sandbox:** toggle defenses, use a dummy secret and inspect attempts; optionally compare Gemini, Groq, OpenAI or Ollama.
5. **Bilingual learning UX:** VI/EN, Web Audio and local best scores. These are product features, not a formal security certification.
